# Website Screenshot Index

**Subject:** https://www.orbix.studio — live production site  
**Captured:** 15 September 2026  
**Method:** Playwright driving installed Google Chrome. Full-page capture (`fullPage`), PNG, device scale factor 1. 
Each page was scrolled top-to-bottom to trigger lazy-loading and Webflow IX2 scroll reveals, all images awaited, 
looping animations frozen, fixed/sticky chrome converted to absolute so it renders once, then captured from scroll position 0.  
**Viewports:** 1440px (desktop) · 768px (tablet, homepage only) · 390px (mobile)  
**Total:** 63 PNG files across 31 pages

> Note: the Lenis smooth-scroll library is blocked during capture only. It changes no layout — it only 
> intercepts scroll position, which corrupts full-page stitching. Everything else runs as the live site does.
